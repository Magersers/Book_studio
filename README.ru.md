# Book Studio

[English](README.md) · **Русский**

Студия для Windows: голосовые аватары, эмоциональная озвучка и аудиокниги с несколькими персонажами. В интерфейсе приложение называется **Vox Studio**.

**Речь создаётся через [RouterAI Drama 3](https://routerai.ru/models/fish-audio/drama-3). Музыка и звуковые эффекты — одной дополнительной локальной моделью Stable Audio 3 Medium.**

[Установка](docs/INSTALL.md) · [Настройка RouterAI](docs/ROUTERAI.md) · [Встроенные голоса](docs/VOICE-PACK.md) · [Сторонние компоненты](THIRD_PARTY.md)

## Запуск из этой версии исходников

1. Скачайте ветку с GitHub: **Code → Download ZIP**. Распакуйте в папку с правом записи.
2. Запустите `setup.cmd`: установятся отдельный Python 3.12 и зависимости интерфейса/API, появится ярлык.
3. В **Озвучка / RouterAI** сохраните ключ RouterAI. Используется модель `fish-audio/drama-3`.
4. Выберите голос из каталога Fish Audio или добавьте аватар с ID своего голоса. Свой голос сначала создайте на Fish Audio, затем скопируйте 32-символьный ID из ссылки на него.
5. Озвучьте текст в студии либо импортируйте книгу, настройте API разметки и назначьте голоса рассказчику и персонажам.

Архив исходников и установщик Windows собираются через `tools/build_release.py`. Перед обновлением существующей установки сохраните `data` и `outputs`, после замены исходников повторите `setup.cmd` в той же папке установки.

## Возможности

- Каталог Fish Audio, папки и поиск голосов. [Прежние русские голосовые образцы](docs/VOICE-PACK.md), личные правки и назначения книги сохраняются.
- Импорт PDF, DOCX, EPUB, FB2, TXT и других поддерживаемых форматов. Добавление глав с сохранением контекста персонажей.
- Разметка рассказчика, диалогов и звуков. Назначение голоса категории, отдельному герою, рассказчику или всей главе.
- Эмоции передаются тегами в тексте, а выбранный голос — его Fish Audio ID. Дополнительные параметры можно задать JSON-объектом в настройках; неподдерживаемые параметры RouterAI может игнорировать.
- Сохранение готовых фрагментов, пауза и продолжение. Экспорт главы в MP3, всех глав в ZIP или всей книги одним MP3. Итоговый MP3 аудиокниги — **44,1 кГц, стерео, 192 кбит/с**; повторная сборка использует сохранённые WAV-фрагменты 24 кГц без нового синтеза речи. Подробности — в [заметках к v0.2.3](docs/RELEASE-v0.2.3.md).
- Параллельная озвучка книги: по умолчанию **3 запроса RouterAI**, настройка **Параллельных запросов** в **Озвучка / RouterAI** допускает **1–8**. Фрагменты сохраняются отдельно и собираются в исходном порядке; платные запросы автоматически не повторяются.
- Независимые галочки **Закадровая музыка — ИИ** и **Звуковые эффекты — ИИ** видны рядом над вкладками аудиокниги. Кнопка **Музыка и звуки книги** открывает настройки эффектов из студии. Музыка сводится тихо, исходная речь сохраняется отдельно. Ручной звуковой файл, чтение автором и пропуск имеют приоритет.
- Прогресс API-запроса, скачивания, локальной генерации и сборки главы. Пока API не сообщает процент синтеза, отображается неопределённый прогресс.
- Русский и английский интерфейс. Язык интерфейса не переводит текст книги и запросы к моделям.

## Что где работает

| Задача | Исполнитель |
| --- | --- |
| Эмоциональная речь с голосами по Fish Audio ID | RouterAI API · Fish Audio Drama 3 |
| Разметка книги, персонажи, музыкальные сцены, подготовка чисел | По умолчанию DeepSeek API; можно настроить OpenRouter или совместимый API |
| Фоновая музыка и звуковые эффекты | Локальная Stable Audio 3 Medium с общими весами |

Для речи нужны интернет, аккаунт и ключ RouterAI. Ключ разметки вводится отдельно; расходы двух API учитываются независимо. Локальная запись через RouterAI не клонируется: сначала создайте голос на Fish Audio и укажите его ID в аватаре. Для каталожных голосов запись и расшифровка не нужны.

Обычная установка использует лёгкие зависимости из `requirements-client.txt`. Локальное окружение звука и около **10,4 ГБ весов** скачиваются при первой генерации музыки/эффектов либо по кнопке **Подготовить музыку и звуки**. Есть прогресс, продолжение загрузки и проверка SHA-256.

Для видеокарты с 8 ГБ памяти предусмотрены блоки до 15 секунд, выгрузка в ОЗУ и декодирование частями. В настройках можно выбрать **CPU**, если GPU использовать не получается. Замеры на ПК с 8 ГБ для этой переделки не проводились. Подробности — в [инструкции установки](docs/INSTALL.md).

## Данные и состояние изменения

Текст озвучки и Fish Audio ID выбранного голоса передаются RouterAI. Текст и контекст разметки — выбранному API разметки. Музыка и эффекты обрабатываются локально. Ключи, сохранённые через интерфейс, зашифрованы Windows DPAPI для текущего пользователя. Личные книги, аватары, ключи и результаты не включаются в Git.

Платный запрос озвучки автоматически не повторяется. После сетевого сбоя продолжение запускается явно: провайдер мог уже обработать прерванный запрос. Актуальную цену и доступность определяет провайдер.

Для RouterAI есть автономные тесты передачи ID голоса, обработки аудио и кэша. Состояние проверки указано в [заметках к версии](docs/RELEASE.md). Условия голосовых записей, моделей и библиотек перечислены в [THIRD_PARTY.md](THIRD_PARTY.md).
