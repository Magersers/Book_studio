# Book Studio

[English](README.md) · **Русский**

Десктопная студия для Windows: голосовые аватары, озвучка текста и аудиокниги с несколькими голосами. В интерфейсе приложение пока называется **Vox Studio**.

[Скачать установщик](../../releases/latest) · [Установка и модели](docs/INSTALL.md)

![Студия голосов](docs/screenshots/studio.png)

## Возможности

- Аватары из аудиофайла или записи микрофона, папки, подпапки и поиск.
- Загрузка PDF, DOCX, EPUB, FB2, TXT и других поддерживаемых форматов. Добавление глав с сохранением предыдущего контекста и реестра персонажей.
- Разметка рассказчика, реплик персонажей и звуков. Портреты персонажей, категории, ручные правки и заметки.
- Голос для всей категории, отдельного героя, рассказчика или главы. Звуковые вставки из файла либо чтение/пропуск.
- Сохранение прогресса, пауза и продолжение, ограниченные повторы неудачного блока API.
- MP3 отдельной главы, ZIP с главами или вся книга одним MP3. Повторная озвучка главы или всей книги.
- Русский и английский интерфейс: выбор в боковой панели, применение после перезапуска. Текст книги и ответы модели не переводятся; часть подробной диагностики движков остаётся на исходном языке.

## Модели

Для локальной озвучки используется **Higgs Audio v3 TTS 4B Q8_0** через audio.cpp v0.9.0, для локальной разметки — **Qwen3.5 9B Q4_K_M** через llama.cpp b11146. CUDA-сборки — 12.4. Распознавание образца использует Whisper. Модели скачиваются при установке, в архив исходников не входят.

Вместо локальной разметки можно выбрать **DeepSeek**, **OpenRouter** или совместимый API: адрес сервера, ключ и модель. Список моделей загружается с сервера, также доступен ручной ввод. Проверка подключения не делает платную генерацию. Выбранная модель должна поддерживать потоковый chat/completions и JSON-ответы. Разметка преимущественно настроена на русские книги.

## Установка

Windows 10/11 x64, видеокарта NVIDIA и подходящий актуальный драйвер. Рабочая конфигурация разработки: RTX 4060 8 ГБ, 32 ГБ RAM. Это не гарантия для любой конфигурации; зависимости и модели занимают несколько гигабайт.

Скачайте `BookStudio-Setup.exe` из [Releases](../../releases/latest), выберите папку и нажмите Install. Установщик скачает Python 3.12, библиотеки, CUDA runtime и модели, создаст ярлык. Для первого запуска нужен интернет. Системный CUDA Toolkit устанавливать не требуется.

Альтернатива: распаковать `BookStudio-source.zip`, запустить `setup.cmd`, затем `start.cmd`. Установщик не подписан сертификатом издателя, поэтому Windows может показать предупреждение. В релизе есть контрольные суммы SHA-256. Перед обновлением сохраняйте копию папок `data` и `outputs`.

Книги, голоса и ключи в публикацию не входят. Ключ API зашифрован для текущего пользователя Windows. При выборе облачной разметки текст и контекст передаются выбранному провайдеру; озвучка выполняется локально. Логи могут содержать текст книги. Условия сторонних моделей и библиотек указаны в [THIRD_PARTY.md](THIRD_PARTY.md).
