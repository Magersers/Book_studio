Book Studio for Windows x64 — voice avatars and multi-voice audiobooks.

- DeepSeek, OpenRouter and custom compatible analysis APIs, with model discovery and manual selection.
- Russian and English desktop interface and documentation.
- Narrator/character/category voices, persistent book progress, avatar folders and searchable voice pickers.
- Separate chapter MP3, chapter ZIP and combined book MP3 exports.

Download **BookStudio-Setup.exe** for the graphical bootstrap installer or **BookStudio-source.zip** to run setup.cmd yourself. Setup downloads Python, dependencies, CUDA runtimes and models; it needs network access and an NVIDIA GPU/driver. The default models are Higgs Audio v3 TTS 4B Q8_0 and Qwen3.5 9B Q4_K_M. The EXE is unsigned. Verify SHA256SUMS.txt after downloading.

No user books, voice samples, model weights or API keys are bundled. Close the app and back up data/outputs before upgrading. See README and THIRD_PARTY.md for scope, limitations and upstream terms.

Русский: установщик автоматически скачивает зависимости и модели. Язык интерфейса выбирается в боковой панели и применяется после перезапуска. Книги и голоса пользователя в архив не включены.
